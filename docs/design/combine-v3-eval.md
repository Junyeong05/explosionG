## 결론

v3 는 210가지를 **규칙 하나**로 다시 만들었다: "A 가 작용하는 순간마다, 그 자리에서 그것이 B 가 된다".
- 따로 쏘는 B 가 없다. 화면에는 총탄이 덫으로 박히고, 덫이 총구로 서고, 포탄이 짐승으로 깨어나는 모습만 있다. 두 무기가 같이 도는 게 아니라 한 무기다.
- 짝마다 짠 동작이 0개다. 몸 15 (언제·어디서 작용하나) × 성질 15 (그것이 무엇이 되나) 로 210가지가 나오고, 겹친 합성(A → B → C)은 같은 규칙이 한 번 더 도는 것이라 따로 이어 붙일 게 없다.
- 숫자도 v2 보다 낫다: 처치 가운데값 ×1.44 → ×1.72, 겹친 합성 92% → 98%, 갈래 전체 무기 97% → 거의 100%.
- 나빠진 것 하나: 방어선에 닿은 적이 v2 (93) 보다 많고 따로 가진 판과 같다 (132). 드물게 작용하는 몸(음파·함정·포격·주문)은 ×1 근처.

## 이번에 손본 것 (v3 를 돌리며)

1. 첫 판: 주문이 성질(X + 주문)이면 0 처치 → 주문이 걸릴 때 피해도 같이.
2. 뚫림 317 (따로 132): A 의 원래 공격이 다 사라져서 → A 의 한 방을 ×0.6 남김, 안에 든 무기 자리에서 합친 무기로 지킴.
3. 주문 + 손이 한 번도 안 함 → 주문 마법진이 손 입력을 막지 않게.
4. 손이 성질일 때 약함 → 손의 탭 공격은 합쳐도 그대로.
5. 음파가 몸이면 ×1.01, 밀침·얼림이 사라져 있었음 → 그것이 B 가 된 다음 음파답게 얼리고 민다(×0.6), 넓게·드물게 치는 몸(음파·함정 ×0.9, 포격·주문 ×0.85)은 한 방을 더 남김 → 음파 ×1.12.
6. 지진(음파)·분열 폭탄(투척)이 규칙에 안 걸림 → 고리·맞음 두 길을 v3 로 이음 (음파·투척 무기로 치면 100%).

## 남은 것과 정할 것

1. **v3 를 게임 기본으로 할지.** 지금 게임 코드는 v2 (`fuse`) 와 v3 (`fuse3`) 를 둘 다 가지고 있다.
2. **드물게 작용하는 몸이 약하다** (음파 ×1.12, 함정 ×1.19). 더 세게 할지, 밀침·묶음 같은 처치 밖 쓸모로 둘지.
3. **방어선**: v2 의 "자리 돌아가며 쏘기" 를 v3 에도 넣을지 (v3 는 그것이 B 가 되는 자리가 적 쪽이라 방어선 가까이가 비기 쉽다).
4. **놀람**: 규칙 하나로 짐작이 쉬워진 만큼, 짝마다 특이점 하나(예: 덫 포탑의 총구가 다른 덫을 밟게 함)를 더 넣을지.
5. 손 입력(잇기·꾹 누르기)을 실제 게임 입력에 넣을지, 레벨 업에서 합치는 방법.
