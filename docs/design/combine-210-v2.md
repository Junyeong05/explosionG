## v1 에서 무엇이 문제였나

- v1 은 "A 가 나를 때 가끔(다섯 발에 한 번 등) B 의 작은 판(피해 ×0.6)이 열린다". 합치면 B 가 따로 쏘던 것을 잃으니 **둘을 따로 가진 것보다 약했다.**
- 열리는 모습도 "A 가 맞은 자리에 B 효과가 하나 더 생긴다" 뿐이라, 210가지가 다 "A + B 를 옆에 붙임" 으로 읽혔다 (손공격 + 투척 = 번개 손 자리에 수류탄).

## v2 의 짜임: A 의 몸 × B 의 동사

- 합친 무기는 A 갈래로 친다. **B 는 A 옆에 붙는 게 아니라 A 가 내보내는 것 자체를 B 처럼 바꾼다.** 빗나간 총탄이 지뢰가 되고, 함정이 터지며 총을 쏘고, 소환수가 낙하산으로 내려오고, 돌격이 핀볼처럼 튕긴다.
- 짝마다 문장은 손으로 썼지만 어느 짝이든 같은 원칙(아래 두 표)에서 나왔다. 새 갈래가 생기면 몸 하나·동사 하나를 정하고 짝 문장을 쓴다.

| 갈래 | A 일 때: 몸 (무엇을 내보내나) | B 일 때: 동사 (어떻게 바꾸나) |
| --- | --- | --- |
| 손공격 | 손가락 (탭·두 탭 잇기·꾹 누르기·연타·박자) | 내 손이 다룬다 (모아 두었다 쏟기·지휘·기폭·꺾기·표적) |
| 총 | 총탄 (빠르게, 많이) | 쏜다 (그 몸이 총탄을 뿌린다) |
| 포격 | 포탄 (멀리, 높이, 크게) | 터진다 (크게, 멀리 있는 무리까지) |
| 소환수 | 소환수 (스스로 적을 맡는 몸) | 일으킨다 (쓰러뜨린·붙잡은 적이 아군으로, 몸에서 소환수가) |
| 주문 | 마법진 (드물게, 몰린 곳에 규칙) | 규칙을 건다 (멈춤·변이·매혹·되돌리기·분신·가속) |
| 함정 | 함정 (미리 깔려 기다림) | 남아서 기다린다 (그 몸이 함정으로 남거나 함정을 깐다) |
| 공중 | 낙하물 (그림자 예고 → 떨어짐) | 하늘에서 (솟았다 내리꽂힌다, 예고 그림자) |
| 돌격 | 달리는 몸 (한 줄을 끝까지) | 꿰뚫고 달린다 (한 줄을 끝까지, 부딪친다) |
| 음파 | 고리 (둘레 전부에 한꺼번에) | 울린다 (밀치고 멈칫, 몰아붙인다) |
| 회전체 | 날 (오래 남아 튕김) | 돈다 (남아서 돌고, 돌아온다) |
| 장판 | 장판 (그 자리에 계속) | 자국을 남긴다 (지나간·맞은 자리가 장판) |
| 광선 | 줄기 (붙어 있을수록 세짐) | 잇는다 (줄로 이어 함께 지지고, 붙어 있을수록 세짐) |
| 투척 | 던진 것 (적 사이를 튕겨 옮겨 감) | 튕긴다 (다음 적으로 옮겨 간다) |
| 떼 | 구름 (덮어서 약하게) | 덮는다 (약화: 느림·받는 피해 ×1.5, 번진다) |
| 정령 | 정령 (혼을 모아 터짐) | 혼을 먹고 자란다 (처치할수록 커지고 늘어난다) |

## 손공격의 정체성: 입력

손은 "내가 고른 곳을 친다" 가 아니라 **입력 방식** 이 정체성이다: 탭 · 두 탭 잇기 · 꾹 누르기 · 연타 · 박자.
- **손 + B** = B 를 내 입력으로 쓰는 새 기술. 선 긋기(철조망·광선 벽·돌격 길), 경로 그리기(폭격 경로·튕김 경로·덧칠), 누른 만큼 모으기(손가락 총구·조준 포격·슬링), 세 점 결계, 박자, 연타로 키우기.
- **A + 손** = 자동이던 A 를 내가 다룬다. 모아 두었다 쏟기(총), 지정 포격, 지휘(소환수), 원격 기폭(함정), 그림자 끌기(공중), 핸들(돌격), 붙잡은 고리(음파), 불러 모으기(회전체), 장판 옮기기, 표적 고정(광선), 꺾기(투척), 떼 부르기, 수동 기폭(정령).
- 그래서 손을 합친 무기는 내가 손을 쓰는 만큼 세지고, 손을 안 쓰면 원래 무기 그대로(또는 모아 두기만) 한다.

## 왜 둘을 따로 가진 것보다 센가

- **B 를 깎지 않는다** (v1 은 ×0.6). B 의 레벨 업도 그대로 효과 세기에 들어간다. 지속·세기는 A 한 방(같은 갈래 가운데값 대비 0.5 ~ 2)에 비례: 한 방이 센 A 일수록 오래·세게.
- **A 의 빈도·수를 B 가 탄다.** 총탄 하나하나가 B 가 되고(유탄·도탄·벌레탄), 함정·포탄·낙하물 하나하나가 B 를 터뜨리고, 소환수 수만큼 B 가 여러 자리에서 쓰인다. B 혼자 쿨다운을 돌 때보다 훨씬 자주.
- **눈덩이**: 쓰러뜨린 적이 아군으로(전향탄·포획·숙주), 처치할수록 커지고 늘어난다(영혼 날·혼 먹는 짐승·포식·혼 튕김).
- **곱하기 약화·규칙**: 떼(받는 피해 ×1.5)·광선(연속 명중 ×3)·주문(멈춤·변이)이 A 의 빈도로 걸려 다른 모든 무기까지 세진다.
- 지금 값: 합친 무기(A) 피해 ×1.6, 쿨다운 ×0.7, B 동사 효과 B 피해 ×1.8, 합친 정령은 혼 8개에 터짐. 아군 동시 5, 겹침 깊이 2.
- 측정 (`npx tsx tools/carry/check2.ts`, 대표 무기 3레벨·18초·두 판): 같은 두 무기를 따로 가진 판 대비 처치 가운데값 ×1.44, 185/210 이 따로보다 많이 잡는다. 목표 ×1.3. ×1 아래는 주로 밀어내기·멈칫처럼 처치로 안 잡히는 쓸모가 큰 짝 (아래 표 맨 끝 칸).

## 겹친 합성

B 가 이미 합친 무기면 B 의 동사가 함께 따라간다. 어느 깊이든 같은 210 규칙을 다시 쓴다.
- **함정 + (총 + 소환수)**: 함정이 터질 때 전방향 총탄 열두 발 (산탄 지뢰), 그 총탄이 전향탄이라 쓰러진 적이 아군으로 일어난다.
- **(총 + 소환수) + 함정**: 총탄이 전향탄이면서 불발 지뢰. 쓰러뜨린 적은 아군으로, 빗나간 탄은 지뢰로.
- **소환수 + (함정 + 총)**: 소환수가 맡은 적 앞에 함정을 깔고 (공병), 그 함정이 밟히면 전방향 총탄 (산탄 지뢰).
- **떼 + (광선 + 주문)**: 구름이 덮은 적들이 줄로 이어져 함께 지져지고 (약점 표적), 그 줄기에 배율 ×2 부터 주문이 붙는다 (주문 집속).

## 정할 것

- 합치는 순간 보상: 둘 다 레벨 +1 을 줄지 (합치는 선택이 바로 "확" 느껴지게)
- 합성 카드: 레벨 업에 짝 제안 / 유저가 직접 고르기 / 둘 다
- 손 입력(두 탭 잇기·꾹 누르기·연타·박자): sim 은 받게 해 뒀다 (누름·뗌·움직임). 게임 화면 입력에 그대로 이어질지
- ×1 아래 짝을 더 세게 할지, 처치 말고 다른 잣대(막아 낸 적 수 등)로도 볼지
