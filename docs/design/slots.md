# 받침 자리 — 언제 합칠지 판단이 생기게 (2026-11-26)

> 유저: "로디드 다이스는 칸이 한정돼 있어서 2+2 가 4 가 아니라 3 이 돼도 합친다. 꽉 채우고 → 합치고 → 다음으로. 근거 있는 판단이 생긴다.
> 이 게임은 무기 수 제한이 없으니 언제 합치는 게 좋은지 판단할 거리가 뭔지 모르겠다."

## 왜 지금은 판단이 없나

- 자리가 무한 → 새 무기는 늘 더하기 (+12%), 합성은 "지금 더 센가"만 본다
- 로디드 다이스의 판단은 **모자람**에서 나온다: 자리가 꽉 참 → 손해를 보고라도 합침 → 빈자리에 새 것 → 다시 꽉 참

## 모자람 후보

| 안 | 무엇이 모자라나 | 판단 | 판정 |
|---|---|---|---|
| **A 받침 자리** | 방어선 위 자리 N | 꽉 차면 합쳐서 자리를 비울까 | **추천**: 가장 분명하고 화면에 보인다 (하단 UI 와 한 몸) |
| B 전력 예산 | 무기마다 전력, 합치면 덜 먹음 | 예산 안에서 조합 | 숫자가 안 보여서 판단이 흐림 |
| C 성장 분산 | 레벨 업이 여러 무기로 흩어짐 | 몰아 키울까 | 이미 있지만 약함 |

본 것
- **자리를 막아도 약해지지 않는다** (27 → 29 웨이브, 판 운 범위 안). 몰아 키우고 합치는 쪽이 오히려 낫다
- 지금 속도면 웨이브 27 까지 무기가 **10개 남짓**이다. 레벨 묶음(×3·×5)으로 고르는 횟수가 늘면 무기 수가 훨씬 늘어서 자리의 의미가 더 커진다
- 자리 6 = 4분쯤 처음 꽉 차고 판의 1/5 동안 꽉 찬 상태 → "채우고 → 합치고 → 넘어가는" 고리가 판에 서너 번

## 제안 (다음 실험)

1. **받침 자리 6**으로 시작, 보스 두 번(10웨이브)마다 +1 (최대 10)
2. **합칠 둘을 직접 고른다**: 꽉 찼을 때 합성 카드 → 가진 무기 중 둘을 고름 (지금은 카드가 짝을 정해 줌 = 판단이 없음)
3. **대기석 1~2칸**: 꽉 찼을 때 새 무기를 받아 두고, 짝이 맞을 때 합치거나 버림
4. 합성 세기는 **보통 짝은 둘 합 언저리(2+2≈3~4)**, 반응 짝은 그보다 크게 (천장 없음 유지) → 자리를 비우려 손해를 보는 합성과 대박을 노리는 합성이 갈린다

판단 거리 (플레이어가 묻게 되는 것)
- 꽉 찼다: 새 무기를 받으려고 약한 둘을 합칠까, 그냥 강화할까
- 등급 = 낮은 레벨: 지금 합쳐 자리를 비울까, 키우고 합쳐 세게 할까
- 어느 둘: 반응 짝(세짐) vs 자리만 비우는 짝(손해)
- 한 몸에 넷까지: 한 몸에 몰까, 몸 둘로 나눌까
