# 합성 천장 후보 여섯 (2026-11-12)

> 기준: 리서치 [`combine-research.md`](combine-research.md) 의 제안 → 유저 "대박 후보 5~6개 미리보기 카드로 만들어 봐".
> 데이터 `src/data/combineCeil.ts`, 동작 `src/sim/fusion.ts` 의 `ceil3` (`Fusion.ceil` 을 켜면 그 짝만 v3 공통 규칙 대신), 측정 `npx tsx tools/carry/ceil.ts`, 미리보기 "합성 천장 후보" https://claude.ai/artifact/96ZCmgRZQVbverTXw4mPEW

## 생각

- 리서치 결론: 확 좋아지는 합성은 한쪽이 다른 쪽의 고질적인 빈틈(때·자리·머묾·수·잦음·세기)을 없애고, 결과가 새 동작·새 이름으로 보인다.
- 그래서 210 전부를 같은 무게로 두지 않는다. 바닥 = v3 공통 규칙 (210 전부), 천장 = 맞물리는 짝만 손으로 짠 새 동작 (목표 20~30, 갈래당 2~4).
- 여섯은 그 첫 후보. 셋은 유저가 "소환 위치만 바뀌었다" 고 한 함정 짝을 빈틈 기준으로 다시 짠 것, 셋은 빈틈 표에서 맞물리는 다른 갈래 짝.

## 여섯

| 짝 | 이름 | 동작 | 채우는 빈틈 |
| --- | --- | --- | --- |
| 함정 + 돌격 | 올가미 돌파 | 덫이 밟히면 밟은 적과 그 뒤로 줄지어 오던 적(여덟까지)이 올가미로 묶여 한 줄로 서고, 0.35초 뒤 돌격이 그 줄을 거슬러 끝까지 꿰뚫는다 (돌격 피해 ×2) | 돌격의 "어느 줄로" 를 덫이 정하고, 묶어서 다 맞게 |
| 함정 + 회전체 | 톱니 올가미 | 덫이 밟히면 둘레 140 을 소용돌이로 끌어당기고(3초), 날 넷(한가운데 하나 + 둘레 셋)이 그 자리를 축으로 돈다 | 회전체의 "적이 빠져나간다" |
| 함정 + 소환수 | 전향 덫 | 밟은 적(넷까지)이 돌아서서 제 무리 속으로 들이받으며 걸어 들어가고, 6초 뒤 그 한가운데서 터진다. 짐승 하나 함께 | 문턱: 적 → 우리 편 → 적진 폭탄 |
| 소환수 + 포격 | 표적 포격 | 짐승은 원래대로 물고, 문 적을 붙잡으면(0.9초) 표적이 찍히고 포탄이 바로 그 위로 (폭발 ×1.5, 짐승마다 0.5초에 한 번) | 포격의 "착탄 지연·앞줄을 못 침" |
| 총 + 주문 | 주문탄 | 총은 원래대로 다 쏘고, 여덟 발 맞힐 때마다 총 위 보라 고리가 차서 다음 한 발이 주문탄: 맞은 무리(80)에 주문이 바로 | 주문의 "언제·어디·드묾" |
| 음파 + 장판 | 용암 해자 | 울릴 때마다 고리 끝을 따라 장판이 반원으로(6초). 다가오는 적은 해자를 건너야 하고, 밀려난 적은 해자 위로 되돌아가 멈칫 | 장판의 "적이 지나가면 끝", 음파의 "세기" |

## 측정 (대표 무기 3레벨, 적 14 유지, 18초 두 판, 같은 두 무기를 따로 가진 판 대비 처치)

| 짝 | v3 | 천장 후보 |
| --- | --- | --- |
| 함정 + 돌격 | ×1.50 | **×1.98** |
| 함정 + 회전체 | ×1.72 | ×1.65 |
| 함정 + 소환수 | ×1.86 | **×1.98** |
| 소환수 + 포격 | ×2.74 | ×2.14 |
| 총 + 주문 | ×1.71 | **×2.10** |
| 음파 + 장판 | ×0.83 | ×0.87 |

- 처음 짠 함정 + 돌격은 ×0.82 였다: 덫이 방어선 앞에 있어 가로 줄에 적이 거의 없었다 (돌격 18번 중 13번이 0명). 적이 줄지어 내려오는 세로 줄을 묶게 바꿔 ×1.98.
- 소환수 + 포격은 v3 (가장 센 짝 중 하나, 문 때마다 근처 무리로 포탄) 보다 처치는 적다. 대신 포탄이 문 적 위에 정확히 떨어지는 게 보인다.
- 음파 + 장판은 음파가 드물게 울려(적이 가까이 와야) 둘 다 ×1 아래. 해자는 잘 보이지만 세기는 아직.
- 처치 비율은 "확 좋아짐" 을 재지 못한다는 게 리서치 결론이라, 판단은 미리보기에서 화면으로.

## 정할 것

- 여섯 중 게임에 넣을 것, 고칠 것, 버릴 것
- 천장을 몇 짝까지 (목표 20~30), 고르는 법 (빈틈 표 점수 / 손으로)
- 천장 짝의 합성 순간 (레벨 업 카드 / 보스 상자 같은 사건)
