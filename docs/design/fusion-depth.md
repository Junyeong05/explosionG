# 여러 단계 합성 — 규칙이 깊이에서도 먹나 (2026-11-28)

> 유저: "규칙들 새로 다 정립이 됐나? 무기 여러 단계 합성으로 들어가도 규칙이 제대로 적용돼서 엄청 다양한 무기들이 연출되는 맛이 어떻게 된 것 같나?"
> 측정 `tools/meeting/depth.ts`: 무작위 40 몸 (뿌리 A + 다른 갈래 B → C → D, 대표 무기 3레벨), 같은 무기를 따로 가진 판과 견줌, 18초 두 판.

- 반응 묶음은 몸 3 · 4 에서 40/40 모두 다름. 깊을수록 안에 든 무기끼리 상태를 이어 줘서 반응이 더 잘 터짐
- 엔진은 깊이 · 2+2 · 사슬 모두 돈다 (11-13 검증 무작위 구조 200 · 잠금 0)

## 모자란 것

1. **셋째부터 이름이 안 바뀜**: "군견 지뢰밭 +1" → 단계마다 새 이름 (예: 셋째 무기의 성질 말을 붙임)
2. **모습이 안 바뀜**: 뿌리 아이콘 + 갈래 색 점뿐 → 단계마다 받침 · 몸 · 탄이 바뀌어야 "새 무기"
3. **짝 둘 중 하나는 극적 반응이 안 보임** (몸 2 에서 45%: 피해는 성질로 들어가지만 화면엔 이름이 안 뜸) → 반응 조건을 넓히거나, 안 터지는 짝은 성질 연출을 크게
4. **메인 몫이 사라짐** (12% → 2%): 메인은 방아쇠만 남음 → 메인 성질도 반응에 섞이게 (메인 + 보조의 "메인")
5. **카드가 깊이를 막음**: 지금 카드는 몸 무기 셋까지 (폭=칸 규칙은 둘), 사슬 · 몸째 합성 카드 없음 → 자리 규칙과 함께 넷까지 · 둘을 직접 고르기
6. 미뤄 둔 것: 등급 함정 · 손공격 B 등급 · 성질 고정 버그, 거절한 합성 카드가 칸을 차지
