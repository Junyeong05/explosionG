## 2. 공통 바닥: 반응 예산 (네 안이 모두 깔고 간다)

업그레이드가 무엇이든 "합성 한 장의 값이 짝마다 1배~15배"면 업그레이드 차이가 묻힌다. 그래서 바닥을 먼저 깐다.

**식** (몸 하나마다, 판 안에서 계산. 표 없음)

```
반응 예산 R(몸) = U × T_G × Σ 종이화력(B, L_B)
  종이화력 = 수치에서 바로: dmg × count × burst ÷ cd (장판은 dps), 무기 데이터에서 계산 → 새 무기 비용 0
  T_G (등급 배율, GRADE_MUL 대신) = G2 1.2 · G3 1.4 · G4 1.6 · G5 1.8  (판에서 맞춤)
  U = 업그레이드가 올리는 값 (안마다 다름)
조속기: 1.5초마다 m ← clamp(m × (R ÷ 관측 반응 피해)^0.5, 0.5, 2)   (실험은 0.25 ~ 4)
넘침 → 공명: 관측 > R 인 몫만큼 공명 게이지가 더 찬다 (V5.resMax 10). 센 짝은 "공명!" 이 더 자주 뜨고, 공명 5초는 예산 ×2 까지 허용
바닥 타이머: 몸 안 B 가 3초 동안 한 번도 안 나가면 B 가 제 자리에서 한 번 나간다 (아랫꼬리)
```

- 극적 반응 이름·연출·순서는 그대로 → 도파민은 남고, **세기만** 예산 안에 든다. "대박 짝"은 더 세지 않고 **더 자주 공명**한다.
- 업그레이드는 U 만 올린다. 조속기가 실제 피해를 예산에 맞추므로 "반응 +7%" 가 **어떤 짝이든 실제로 +7%** 가 된다 (지금은 같은 +% 가 짝마다 다르게 먹는다).
- 자리: `Chaos.gradeMul` (fusion.ts 1368행 `unit = V4.base * c.gradeMul(A.id)`) 하나를 `reactMul(A, B)` 로 바꾸면 drama4 · trait5 · 넘침에 다 걸린다. 피해 몫은 이미 `noteDamage` 가 무기별로 잰다.
- 실험값: 대표 70 처치 p90/p10 5.4 → 3.8, 다른 무기 60 5.8 → 4.5 (바닥 타이머 없이). 목표 2.5 까지는 바닥 타이머 + clamp 맞추기가 남았다.
- 합성 기계 연구 (회의안: G5 열기, 도감 12 → 몸 셋째 자리)는 어느 안이든 그대로 둔다. 다만 T_G 상한을 넘기지 않게.

**화면**: 노심 5단계(Lv 0/5/10/15/20)마다 **모든 공격의 빛·꼬리·폭발 고리가 한 단계** 바뀜 → 무기 20개가 한꺼번에 달라져서 "키운 게 한눈에". 업그레이드 화면에 같은 씨앗 10초 판을 Lv n / n+1 나란히 (시뮬이 결정적이라 공짜).

**합성 · 세계 · 파이프라인**: 폭=칸·등급 그대로, 공명로가 합성만 키우므로 상한 5. 세계와 무관 (빛 단계가 세계 그림 말투와 부딪칠 수 있음). 새 무기 비용 0.

**구현**: `src/data/upgrades.ts` (줄 셋, 화력 흡수) · `src/sim/stats.ts` MetaModifiers (coreMul · cdMul · resMax) · `src/sim/chaos.ts` dmgMul · cooldownOf · `src/sim/fusion.ts` charge5 · `src/render/chaosDraw.ts` 빛 단계 · `src/ui/screens.ts` (업그레이드 화면 4줄이 이미 있음). 가장 작다 (2~3일).

## 5. 순위와 먼저 만들 것

1. **A 갈래 숙련** — 편차를 가장 많이 설명하는 단위(갈래 × 역할)에 업그레이드를 건다. 새 무기 비용 0, 판 안 새 카드 0, "넓게 키울수록 이득"이라 유저 원칙과 같은 방향. 보임은 색 고리 + Lv 4·8 모양 단계로 메운다.
2. **B 공용 노심** — 가장 싸고 편차가 가장 좁지만 유저가 싫어한 숫자 놀이. A 와 따로 만들지 말고 **지금 '화력'을 A 의 손공격 몸 숙련으로 옮기고, 빛 단계 아이디어만 A 에 가져온다.**
3. **D 세계 인장** — 업그레이드로서는 약하지만 보임은 가장 좋다. 그림 방향이 정해진 뒤 **힘은 작게(+6~20%), 겉모습·수집 층으로** A 위에 얹는다.
4. **C 문법 연구** — A 의 반응 숙련 Lv 4·8 (대상 수)이 문법의 보이는 몫을 이미 가져간다. 남는 건 추상적이고 합성만 세진다.

**먼저 만들 것 (순서)**
1. 바닥 (2~3일): `reactMul` (예산 · 조속기 · 넘침 → 공명 · 바닥 타이머)을 폭=칸 규칙에만 켜고, 210 + 다른 무기 60 + 봇 12판. 합격선: 합침 처치 p90/p10 ≤ 2.5, ×1.2 미만 ≤ 5%, 봇 웨이브 ±5%. 실패하면 clamp 0.5~2 ↔ 0.33~3, 바닥 타이머 3초 ↔ 2초
2. 미리보기 HTML (CLAUDE.md 규칙): 같은 짝을 숙련 0 / 4 / 8 로 나란히, 반응 단계 글 · 고리 눈금 · 대상 수가 보이게 → 유저 확인
3. A 최소판: 30줄 % + 반응 단계 글 + 무기 자리 눈금 + 결과 화면 자격 막대. 측정: 숙련 0 / 4 / 8 계정 봇 12판 → 만렙 +10 웨이브 이상, 만렙 p25 ≥ 새 계정 가운데값

## 7. 이번에 새로 드러난 것 (다른 역할에 넘김)
