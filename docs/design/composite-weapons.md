# 합성 무기: 합친 것을 또 합친다 (2026-11-10, 가능성 검토)

유저: "총 + 소환수면 총 쏠 때 소환수가 나가고, 그것도 총으로 카운트된다. 그 총을 다시 함정이랑 조합할 수 있다(함정 + 총 혹은 총 + 함정).
유저가 본인만의 무기를 만드는 맛. 모든 조합을 다 짜 두는 게 아니라 210개에서 공통으로 성립하는 규칙만 있으면 구현 가능하다고 보는데,
갈래가 이만큼이라 쉽지 않을 것 같다. feasible 한가?"

## 결론

**가능하다.** 규칙이 무기가 아니라 갈래에만 걸려 있어서, 만들 양은 조합 수(210, 겹치면 끝없음)가 아니라 **갈래 수(15)에 비례**한다.
대신 지금 코드의 "무기 = id 하나, 자리 하나" 구조를 **"무기 = 나무(뿌리 + 실은 것들)"**로 바꾸는 작업이 먼저 필요하다. 이게 제일 크다.

## 구조

- 합성 무기 = 나무. **뿌리 무기가 갈래를 정한다** (총 + 소환수 → 총). 뿌리는 원래대로 쏘고, 나를 때(그 갈래의 트리거)마다 실은 것을 연다.
- 실은 것도 나무다. 함정 + (총 + 소환수) = 함정이 밟히면 작은 총이 서서 2초 난사하고, 그 총의 다섯 발 중 한 발마다 소환수가 나온다.
- (총 + 소환수) + 함정 = 총이 실은 것이 둘이 된다 [소환수, 함정]. 나를 때마다 돌아가며 연다.
- 어떤 깊이에서도 쓰는 규칙은 210표의 "A가 나를 때 × B가 실릴 때" 그대로다. B 가 합성 무기면 B의 뿌리 갈래로 실린다.

| 들어가는 것 | 수 | 겹쳐도 늘지 않는 이유 |
| --- | --- | --- |
| 갈래마다 "나를 때" 걸이 (총탄 맞음, 포탄 떨어짐, 함정 밟힘…) | 15 | 뿌리 갈래 하나에만 달린다 |
| 갈래마다 "실릴 때" 작은 판 (아무 자리에서 짧게 한 번) | 15 | 실린 것의 뿌리 갈래로 고른다 |
| 같은 갈래끼리 (총 + 총) | 1 | 공통: "쏠 때 둘 다 나간다" |
| 겹침 안전장치 (깊이·세기·빈도 상한) | 1 | 모든 나무에 같게 |

## 구현에서 문제 될 것과 막는 법

1. **무기 인스턴스 구조 (가장 큼)**. 지금 `sim/chaos.ts` 는 무기를 id 로 찾고 쿨다운·자리·겨눔을 id 별 지도에 둔다.
   실린 총은 "아무 자리에 잠깐 서는 무기"라서, 무기 하나를 `{ 무기, 레벨, 자리, 세기, 깊이, 실은 것 }` 인스턴스로 다루게 바꿔야 한다.
   지금 쏘는 코드(`fire`)는 그대로 두고, "어디서 쏘나"만 인스턴스에서 받게 바꾸면 된다.
2. **갈래마다 "아무 자리에서 짧게"**. 소환수·투척·함정·공중·장판·떼·회전체·돌격은 자리만 주면 바로 된다.
   총·광선·음파·포격·정령은 "잠깐 서는 자리"가 필요하다 (작은 무기가 2~3초 떠 있다 사라짐). 주문은 자리 중심으로 거는 것(멈춤·변이·되돌리기·매혹)만 실린다.
3. **폭주 (개수가 곱으로 불어남)**. 총(초당 10발) → 다섯 발에 한 번 작은 총(2초) → 그 총도 다섯 발에 한 번 소환수…
   - 깊이 상한 3 (뿌리 + 실은 것 2단)
   - 깊이마다 세기 ×0.5, 지속 ×0.6
   - 나무의 마디마다 동시에 떠 있는 실린 것 최대 3개, 초당 여는 횟수 상한
   - 화면 전체 물체 상한(지금 420)에 닿으면 깊은 것부터 안 연다 (멈추지 않고 덜 연다)
4. **읽히는가**. 실린 것이 열릴 때 작은 고리 + 실은 쪽 색 → 실린 쪽 색. 이름은 실은 것을 앞에 붙여 만든다 (산탄총 + 군견 → "소환 산탄총", 거기에 함정 → "덫·소환 산탄총").
5. **고르는 방식**. 합칠 때 B 는 A 안으로 들어가고 따로 쏘지 않는다 (만드는 맛 + 힘이 무한히 쌓이지 않음).
   레벨 업에 "합성" 카드: 가진 무기 중 짝 세 개를 제안하고, "직접 고르기"로 A·B 를 두 번 눌러 고를 수도 있게.
6. **밸런스**. 나무가 깊을수록 셀 수밖에 없으니, 측정 도구(dps·봇)를 나무 단위로 돌려 깊이별 배율을 맞춘다.
7. **시험**. 갈래 15개로 깊이 3까지 무작위 나무 수백 개를 30초씩 돌려 예외 없음, 물체 수 상한 안, 같은 씨앗이면 같은 결과인지 본다.

## 11-10 유저 결정 → 구현

유저: "15P2 라 210개 만들어야 하는 거 아냐? 210개가 많아 보여도 나올 수 있는 조합(2종+1종이면 15P3, 2종+2종…)에 비하면 작은 수.
주문이면 총은 몇 번째 총알마다 멈춤·변이, 지속시간은 데미지에 비례, 발동 간격은 공격 속도에 따라가게 하면 다른 데도 다 된다. 광선은 특수하게.
규칙을 유저에게 무조건 공개하지 않고 직접 찾아가는 맛. 210종 규칙 싹 정리하고 샘플 하나씩 뽑아 줘. 보고 어색한 거 검증하게."

- 210 규칙 = 갈래마다 나를 때(CARRY) × 실릴 때(PAYLOAD). 짝마다 따로 짠 것은 없다. 겹친 합성(15P3 이상)은 같은 210 규칙을 다시 쓴다.
- 지속·피해는 세기 k (나르는 무기의 한 방 ÷ 같은 갈래 가운데값, 0.5~2) 에 비례, 간격은 "몇 번에 한 번"이라 공격 속도를 따라간다. 광선은 배율이 0.5 오를 때마다 (특수).
- 규칙 문장은 게임 안에 안 보인다. 문서·미리보기는 검증용.
- 구현: `src/data/links.ts` (CARRY · PAYLOAD · LINK · SAMPLE), `src/sim/chaos.ts` (`attach` · `carry` · `open` · `payload`). 아직 레벨 업에 합성 카드는 없다 (미리보기·테스트에서만 합침).
- 규칙표 전부: [`combine-210-v1.md`](combine-210-v1.md). 미리보기 "합성 210": 210 카드 + 겹친 합성 3 카드.
- 검증: `npx tsx tools/carry/check.ts` 로 210가지를 미리보기 조건(18초)으로 돌려 전부 열림 (짝당 4~32번). 테스트 `tests/combine.test.ts` (210 전부 열림, 깊이 2 상한, 같은 씨앗 같은 결과, 무작위로 겹친 40개 물체 수 상한 안).
- 처음 돌려 보고 고친 것: 정령은 두 마리가 처치를 나눠 18초에 혼 열 개가 안 모여 한 번도 안 열림 → "혼 두 개마다, 적이 죽은 자리". 광선은 표적이 금방 죽어 ×2 에 못 감 → "배율 0.5마다". 소환수는 한 마리에 한 번이라 드묾 → "맡은 적마다".

## 11-10 v2: 합치면 새 무기 (v1 은 보관)

유저 (v1 을 보고): "합쳤으면 둘을 따로 가진 것(100% + 100%)보다 확실히 좋아야 한다. 무기 수 제한이 없어 합쳐서 150% 가 되는 선택을 할 이유가 없다.
함정 + 총은 함정이 터질 때 전방향으로 총알을 퐉. 함정 + (총 + 소환수) 면 소환수가 담긴 총알." /
"손공격 → 투척을 보니 손공격에 나머지 효과가 딱 붙어 있는 정도. 손으로 클릭하는 건 그것만의 아이덴티티가 있어야 한다." /
"지금 것도 따로 저장해 두고, 새로 만드는 건 새 파일로."

- v1 보관: 규칙표 [`combine-210-v1.md`](combine-210-v1.md), 코드 커밋 `12a3fb9` (`src/data/links.ts` CARRY·PAYLOAD, `src/sim/chaos.ts` attach·carry·payload), 미리보기 "합성 210" 그대로.
- v2 새 파일: 데이터 `src/data/combineV2.ts` (손으로 쓴 210, 이름 210개), 규칙표 [`combine-210-v2.md`](combine-210-v2.md).
- v2 구현 (같은 날, 유저 "여기서 열 수 있게, 발사되는 게 보이게"): `src/sim/fusion.ts` (Chaos.fuse, 210가지 전부), 미리보기 "합성 210 v2" (210 카드 + 겹친 합성 4, 손이 든 짝은 입력 자동). 처음 돌렸을 땐 31가지가 안 했고 합친 판이 따로 가진 판보다 약했다 (×0.85) → 손은 합쳐도 탭 공격 그대로, 합친 음파는 적이 없어도 울림, 합친 무기 피해 ×1.6·쿨다운 ×0.7, 동사 효과 ×1.8 → 210가지 다 하고 가운데값 ×1.35.
- 짜임: 합친 무기 = A 의 몸 × B 의 동사. B 가 A 옆에 효과를 붙이는 게 아니라 A 가 내보내는 것 자체를 B 처럼 바꾼다 (빗나간 총탄이 지뢰, 함정이 터지며 총, 소환수가 낙하산, 돌격이 핀볼).
- 세기: B 를 깎지 않음, A 의 빈도·수를 B 가 탐, 눈덩이(전향·포획·처치마다 성장), 목표 합친 하나 ≥ (A + B) × 1.3.
- 손공격 = 입력이 정체성 (탭·두 탭 잇기·꾹 누르기·연타·박자). 손 + B 는 B 를 입력으로 쓰는 새 기술, A + 손 은 자동이던 A 를 내가 다룸.
