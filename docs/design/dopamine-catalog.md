# 도파민 모드: 카테고리 무기고 121종 (2026-11-07)

## 흐름

1. 유저 요청 1: "이런 류에서 나올 법한 걸 싹 다 넣자. 도파민에 미친 게임. 공룡, 대포, 외계인, 동물 떼 다 좋다."
   → v1: 난입 이벤트 14종이 첫 웨이브부터 저절로 쏟아지고, 설치물이 레벨 업 카드로 섞였다.
2. 유저 요청 2: "생각한 건 카테고리(포탑·소환수·손공격·마법…)를 나누고 그 안에 종류를 쫙 둔 다음,
   **하나 골라서 시작해서 플레이하며 하나씩 늘려 가는** 것. 지금 건 시작부터 다 들고 있는 느낌.
   초반엔 다른 디펜스처럼 조촐하다가 이것저것 업그레이드하게."
   → v2: 뱀파이어 서바이버식 무기고. v1 의 난입은 "마법" 무기로, 설치물은 "포탑·소환수" 무기로 옮겼다.
3. 유저 요청 3: 무기를 확 늘리고, 총은 총처럼, 칸 제한 해제, 무기마다 사거리.
   → v3: 121종, "총" 카테고리 추가(벽에 붙어 겨누는 총), 칸 제한 없음, 사거리 기본 280.
4. 유저 요청 4: 엔드리스로, 시작 선택지 3개. 무기마다 업그레이드 차이는 그다음에.
   → **v4 (지금)**

## 규칙 (v3)

유저 요청 3: "무기 종류 확확 늘리자, 진짜 많이 (나중에 해금으로 풀면 됨). 총도 종류가 다양할 테니 총은 총처럼.
무기 개수 제한은 싹 풀자." + "무기마다 사거리를 다르게. 다 맨 끝까지 치니 적이 나오는 게 안 보인다. 보통 절반에서 조금씩 차이."

- **엔드리스** (유저 요청 4: "도파민 모드는 엔드리스로"). 타이틀 버튼·실험실 ▶ 모두 엔드리스로 시작.
- 판 시작: **시작 무기 고르기 3장** (유저 요청 4: "선택지는 3개 정도로"). 손공격·총·포탑·소환수·마법 중 세 갈래에서 한 장씩.
- 레벨 업마다 3장: 가진 무기 레벨 업 / 새 무기 / 강화. 무기는 최대 5레벨. **칸 제한 없음.**
  폭탄 탭을 가졌으면 기존 탭 증강(폭발 반경·연쇄 단계 등)도 가끔 섞인다.
- **사거리**: 자동 무기는 사거리 안의 적만 노린다. 기본 280(화면 높이 560의 절반), 무기마다 140~480.
  자리 있는 무기(총·포탑·던지는 소환수)는 자리에서 반경, 마법·돌진하는 소환수는 방어선에서 위로. 화면에 "사거리" 점선.
  🔭 사거리 강화로 늘어난다. 손공격은 탭한 자리라 사거리 없음.
- **총**: 첫 총은 방어선 가운데, 그다음부터 양옆 벽에 번갈아 아래부터 위로 붙는다. 모양(총열·몸통·개머리판·조준경·탄창·
  다총열·연료통·빛)을 총마다 다르게 벡터로 그리고, 겨누는 방향으로 돌며, 쏠 때 반동·총구 불꽃·탄피가 튄다.
  탄은 예광탄·화살·로켓·에너지 구슬·화염·이모지(팝콘·표창)로 날아간다.
- 손공격이 하나도 없으면 탭은 아무 일도 안 한다. 마법은 쿨다운마다 저절로.
- 무기 폭발은 연쇄 1단계까지만 잇는다. 그보다 깊은 연쇄는 폭탄 탭(과충전) 몫.
- 덤: 피버 타임(짧은 시간에 40마리), 황금 쿠키(웨이브 3부터 40초마다).

## 봇 결과 (v3, 시작 무기별 6~8판, 챕터 1)

적 체력 × (1 + 0.32 × (웨이브-1)), 무리 간격 × max(0.55, 1 - 0.035 × (웨이브-1)), 경험치 ×1.6.
