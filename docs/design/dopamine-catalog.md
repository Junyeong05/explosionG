# 도파민 모드: 다 쏟아붓기 목록 (2026-11-07)

유저 요청: "이런 류에서 나올 법한 거 싹 다 찾아서 집어넣자. 도파민에 미친 게임. 쌩뚱맞아도 된다. 공룡이 나와도, 대포가 쏴도,
외계인이 하늘에서 쏴도, 동물들이 달려들어도 된다. 초반엔 하나씩 해금하고, 나중엔 미친 듯이 다 깔려 있게."

✅ = 프로토타입에 들어감 (타이틀 → 🔥 도파민 모드), ⬜ = 아직 목록에만.

이 게임만의 규칙 하나: **다 깔려도 깊은 연쇄는 탭 몫.** 난입·설치물 폭발은 연쇄 1단계만 잇고(폭발형·폭약 붙은 적까지만 터짐),
과충전 탭이 2단계 이상을 연다. 그래야 "보고만 있어도 되는" 디펜스가 안 된다 (11-04 플레이 피드백).

## 봇 결과 (프로토타입 수치)

적 체력 × (1.5 + 0.28 × (웨이브-1)), 무리 간격 ×0.6. 판당 난입 약 70회, 설치물 15개, 피버 6번. 봇은 황금 쿠키를 거의 안 누른다.

| 설정 | 챕터 1 | 챕터 2 |
| --- | --- | --- |
| 체력 ×1.8 고정 | 100% | — |
| 체력 ×5 고정, 무리 ×0.6 | 25% | 63% |
| 체력 ×(1.5 + 0.22/웨이브) | 100% | 90% |
| 체력 ×(1.5 + 0.30/웨이브) | 50% | 30% |
| 체력 ×(1.5 + 0.26/웨이브), 난입 8초·20초 간격 | 83% | 58% |
| 난입 4초·14초 간격으로 당김 + 체력 0.26/웨이브 | 90% | 80% |
| 같은 간격 + 체력 0.30/웨이브 | 42% | 42% |
| **같은 간격 + 체력 0.28/웨이브 (채택)** | **75%** | **67%** |

처음부터 단단하면 설치물이 깔리기 전에 무너져서 판마다 들쭉날쭉했다. 초반엔 한 방에 쓸리고 후반에 단단해지게 웨이브마다 올렸다.
첫 난입 8초·간격 20초는 직접 20초 해보니 난입이 한 번뿐이라 심심해서 4초·14초로 당겼다.
